# Сервер: аккаунты и рейтинг

Игра работает и без сервера — тогда вход гостевой, а статистика лежит
на устройстве. Сервер нужен, чтобы профиль ездил за игроком и появился
общий рейтинг.

Хостинг — **Deno Deploy**: бесплатный тариф, вход по GitHub, карта не
нужна, база данных встроенная. Всё, что от вас требуется, — пять шагов
в браузере.

## Шаг 1. Создать проект

1. Открыть **https://deno.com/deploy** и нажать **Sign in with GitHub**.
   Отдельный аккаунт заводить не надо — подойдёт тот же GitHub, где лежит игра.
2. Нажать **New Project** → **Deploy from GitHub repository**.
3. Выбрать репозиторий с нардами.

## Шаг 2. Указать точку входа

В поле **Entrypoint** написать:

```
server/main.ts
```

Ветку оставить `main`, сборку (build step) не включать.

## Шаг 3. Вписать токен бота

Открыть **Settings → Environment Variables** и добавить две переменные:

| Имя | Значение |
| --- | --- |
| `BOT_TOKEN` | токен вашего бота из @BotFather |
| `ORIGIN` | `https://kutuzovilya.github.io` |

Токен — это пароль от бота. Вписывайте его только сюда, в панель
Deno Deploy. Ни мне, ни куда-либо ещё отправлять его не нужно.

`ORIGIN` закрывает сервер от чужих сайтов: запросы будет принимать
только страница игры.

## Шаг 4. Задеплоить

Нажать **Deploy**. Через полминуты появится адрес вида
`https://нарды-что-то.deno.dev`. Откройте его — должно ответить:

```json
{"ok":true,"service":"nardy"}
```

## Шаг 5. Прислать мне адрес

Пришлите этот адрес — я впишу его в игру (одна строка в `js/account.js`),
и вход станет настоящим.

Проверить, что всё сошлось, можно так: откройте игру в Telegram —
на первом экране вместо «Играть гостем» появится «Войти как <ваше имя>».

## Что делает сервер

* **Вход.** Telegram передаёт странице подписанные данные о пользователе.
  Сервер проверяет подпись секретом, выведенным из токена бота, —
  подделать чужой аккаунт нельзя.
* **Итоги партий.** Результат присылают **оба** игрока. Партия
  засчитывается, только когда обе стороны сообщили один и тот же исход:
  один заявил победу, другой — поражение. Один игрок себе победу
  не припишет, и двое «победителей» тоже не пройдут.
* **Профиль и рейтинг.** Победы, поражения, марсы, счёт против каждого
  соперника и трое самых частых — «братишки».

Партии против компьютера на сервер не уходят: подтверждать их некому,
они остаются в местной статистике.

## Если захочется держать сервер у себя

Тот же код запускается под Node:

```bash
BOT_TOKEN=токен_бота node server/node.mjs 8787
```

Данные лягут в `server/.data.json`. Это удобно для проверки на своей
машине; для боевой работы нужен адрес с https, иначе Telegram не пустит.
