# Сервер нард

Игра работает и без сервера: вход гостевой, статистика лежит на телефоне,
а партия по сети ходит через бесплатный ретранслятор ntfy.sh. Свой сервер
нужен для трёх вещей:

* **Честная сетевая партия.** Кости бросает сервер, каждый ход он
  проверяет теми же правилами, что и игра. Подкрутить бросок или
  приписать себе победу с телефона нельзя.
* **Часы и матч.** 60 секунд на ход по выбору создателя стола, матч до
  N побед или игра подряд без счёта.
* **Общий профиль.** Победы, марсы, серии, последние партии, «кто кого»
  против каждого соперника и братишки — на всех устройствах сразу.

Хостинг — **Deno Deploy**, бесплатный тариф: вход по GitHub, карта не
нужна, база данных встроенная. От вас — один раз пройти шаги ниже,
минут десять. Дальше сервер сам обновляется, когда я выкладываю код.

## Шаг 1. Войти

Открыть **https://console.deno.com** → **Sign in with GitHub**.
Подойдёт тот же GitHub, где лежит игра.

Попросит придумать организацию — впишите, например, `nardy`.
Имя потом не меняется, но ни на что не влияет.

## Шаг 2. Создать приложение

1. Нажать **+ New App**.
2. Выбрать репозиторий **nardy**. Если его нет в списке — нажать
   **Configure GitHub App permissions** и дать доступ к этому репозиторию.
3. В настройках сборки:

| Поле | Что выбрать |
| --- | --- |
| Framework preset | **No Preset** |
| Runtime | **Dynamic** |
| Dynamic Entrypoint | `server/main.ts` |
| Install command, Build command | оставить пустыми |

## Шаг 3. Вписать токен бота

Там же нажать **Add/Edit environment variables** и добавить две:

| Имя | Значение | Тип |
| --- | --- | --- |
| `BOT_TOKEN` | токен бота | **Secret** |
| `ORIGIN` | `https://kutuzovilya.github.io` | обычный |

Токен берётся у **@BotFather**: `/mybots` → `vashi_nardy_bot` → **API Token**.

Токен — это пароль от бота. Вписывайте его только сюда, в панель
Deno Deploy. Ни мне, ни куда-либо ещё отправлять его не нужно.

`ORIGIN` закрывает сервер от чужих сайтов: запросы примет только
страница игры.

Нажать **Create App**.

## Шаг 4. Подключить базу

1. Слева **Databases** → **Provision Database** → **Deno KV**.
2. Имя — любое, например `nardy` → сохранить.
3. В списке баз нажать **Assign** → выбрать приложение нард.

Если после этого у приложения есть кнопка **Redeploy** — нажмите её,
чтобы оно подхватило базу.

## Шаг 5. Проверить и прислать адрес

У приложения появится адрес вида `https://nardy.nardy.deno.net`
(имя приложения, точка, имя организации). Откройте его — должно ответить:

```json
{"ok":true,"service":"nardy","v":2}
```

Пришлите мне этот адрес. Я впишу его в игру — одна строка в
`js/account.js` — и после выкладки заработают вход, профиль и честная
сетевая партия.

## Как это устроено

* **Вход.** Telegram передаёт странице подписанные данные о пользователе.
  Сервер проверяет подпись секретом, выведенным из токена бота, —
  подделать чужой аккаунт нельзя.
* **Стол.** Пишет его только сервер. Телефон присылает ход целиком,
  сервер прогоняет каждую шашку через правила (`js/engine.js` — тот же
  файл, что в игре) и сразу бросает кости следующему. Место за столом
  держится секретным ключом, который получает только севший.
* **Ожидание хода.** Телефон спрашивает «что нового?», сервер держит
  вопрос до 25 секунд и отвечает, как только соперник сходил.
* **Часы.** Время вышло — за игрока ходит компьютер. Третья просрочка
  подряд — поражение. Свой ход обнуляет счётчик.
* **Итог.** Победу записывает сам сервер в момент, когда снята последняя
  шашка. Марс — одно очко, как любая победа, но в профиле считается
  отдельно.

Партии против компьютера на сервер не уходят — они остаются в местной
статистике на телефоне.

## Проверка у себя

Тот же код запускается под Node:

```bash
BOT_TOKEN=токен_бота node server/node.mjs 8787
```

Данные лягут в `server/.store.json`. Чтобы игра на своей машине ходила
в этот сервер, в консоли браузера:

```js
localStorage.setItem('nardy.api', 'http://localhost:8787'); location.reload();
```

Для боевой работы нужен адрес с https, иначе Telegram не пустит.
